# Symbolic UI icons

These SVGs are adapted from the [Adwaita Icon Theme](https://gitlab.gnome.org/GNOME/adwaita-icon-theme)
symbolic set and bundled with Jottr for consistent UI chrome offline and in
packaged builds.
